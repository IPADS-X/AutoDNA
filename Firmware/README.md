## PLC

The process running the code requires **inoshop v1.7.3** IDE. The procedure includes installing the software and the **SP3 patch**, then opening and extracting a project archive, and finally compiling the individual machine codes for PLC hardware. You can download the IDE from [here](https://www.inovance.com/). Check the PLC [tutorial](./tutorial/PLC/tutorial.md) for detailed steps.

***

## C#

The process for running the code requires **Visual Studio 2017** and the appropriate **.NET Framework** components. The procedure includes opening the `.sln` file, building the solution, and then starting the application with or without debugging. Check the C# [tutorial](./tutorial/C-Sharp/tutorial.md) for detailed steps.
