## C\# Project Readme

This short guide explains how to open and run the C\# code in this repository using the specified Integrated Development Environment (IDE).

### Prerequisites

* **Visual Studio 2017** installed on your machine.
* The necessary **.NET Framework** components (usually selected during VS 2017 installation).

### How to Run the Code

1.  **Open the Solution:**
    * Locate the main solution file for this project (it will have the extension **`.sln`**).
    * Double-click the **`.sln`** file. This will automatically launch **Visual Studio 2017** and load the entire project structure.

2.  **Verify Project:**
    * In the **Solution Explorer** window (typically on the right side), ensure all project files and references are loaded correctly. If any files appear with an exclamation mark, you may need to resolve missing references or install a required NuGet package.

3.  **Build the Project:**
    * Before running, it is best practice to build the solution.
    * Go to the menu bar and select **Build** $\rightarrow$ **Build Solution** (or press **Ctrl + Shift + B**).
    * Check the **Output** window at the bottom of the screen to confirm that the build succeeded with "0 errors."

4.  **Run the Application:**
    * To execute the code, use one of the following methods:
        * **Start with Debugging:** Click the **green "Start" button** (which may show "Local Windows Debugger") on the toolbar, or press **F5**. This mode is ideal for tracking down issues.
        * **Start Without Debugging:** Go to **Debug** $\rightarrow$ **Start Without Debugging** (or press **Ctrl + F5**). This is typically faster for quick testing and viewing console application output.

The application will now launch.
